# GarageMind

GarageMind is an auto-parts recommendation assistant focused on **referral monetization for tires and wheels**.  The core flow requires no VIN: a user submits a category preference and receives a small set of ranked product cards with affiliate links.  VIN decoding and photo-based part recognition are retained as optional, secondary capabilities.

## Product flow

```
User picks category (tires / wheels)
         │
         ▼
GET /api/recommendations?category=tires
         │
         ▼
RecommendationService → PartnerRegistry → RecommendationRanker
         │
         ▼
Ranked product cards with affiliate URLs
         │
User clicks → POST /api/clicks  (event logged for attribution)
```

Partner-aware ranking gives a score boost to products from partners that have an active affiliate agreement, so affiliate-enabled sources appear first when price and availability are comparable.

## Referral monetization

Each product card carries an `affiliate_url` generated by `AffiliateLinkBuilder`.  When a partner has `affiliate_enabled=True` and a configured `affiliate_tag`, the URL includes a `ref=<tag>` query parameter that the partner uses to attribute the sale.

Click events are recorded via `POST /api/clicks` and stored by `ClickTrackingService`.  In the current MVP events are in-memory; a future iteration can persist them to a database without changing the API surface.

### Ranking formula

```
affiliate_component = partner.priority_weight  if affiliate_enabled  else 0.0
price_component     = 1.0 − (price / max_price)   # lower price → higher score
score               = affiliate_component × 0.40 + price_component × 0.60
```

`priority_weight` and `affiliate_enabled` are set per-partner in `PartnerRegistry`.  Adding a new partner or changing commission tiers only requires updating the registry — no ranking code changes needed.

## API

### `GET /api/recommendations`

Returns ranked tire or wheel recommendation cards.  No VIN required.

| Query param | Required | Values |
| --- | --- | --- |
| `category` | No | `tires`, `wheels`.  Omit to get both. |

#### Example

```bash
curl "http://127.0.0.1:8000/api/recommendations?category=tires"
```

#### Success response

```json
{
  "recommendations": [
    {
      "product_id": "tire_001",
      "name": "Nokian Tyres Hakkapeliitta 10 205/55 R16",
      "category": "tires",
      "price": 8500.0,
      "image_url": null,
      "description": "Winter studded tire, excellent grip on ice",
      "partner": {
        "id": "partner_ozon",
        "name": "Ozon",
        "affiliate_enabled": true
      },
      "affiliate_url": "https://ozon.ru/catalog/tire_001?ref=garagemind_ozon",
      "score": 0.5893,
      "reason": "partner offer from Ozon, competitive price"
    }
  ]
}
```

### `POST /api/clicks`

Records an outbound affiliate click for attribution.

#### Request body

```json
{
  "product_id": "tire_001",
  "partner_id": "partner_ozon",
  "affiliate_url": "https://ozon.ru/catalog/tire_001?ref=garagemind_ozon"
}
```

#### Success response (`201 Created`)

```json
{
  "recorded": true,
  "event": {
    "product_id": "tire_001",
    "partner_id": "partner_ozon",
    "affiliate_url": "https://ozon.ru/catalog/tire_001?ref=garagemind_ozon",
    "timestamp": "2026-06-23T11:00:00+00:00"
  }
}
```

### `POST /api/recognize-part` *(secondary)*

Accepts either `multipart/form-data` with an `image` file field or JSON with a base64 payload.

```bash
curl -X POST http://127.0.0.1:8000/api/recognize-part \
  -F "image=@/absolute/path/to/brake-pad.png"
```

### `GET|POST /api/decode-vin` *(secondary)*

Accepts a VIN either as a `vin` query parameter or in a JSON body.

```bash
curl "http://127.0.0.1:8000/api/decode-vin?vin=1HGCM82633A004352"
```

## Engineering notes

- Handlers stay thin; validation and business logic live in services.
- `RecommendationRanker` is deterministic: given the same partners and products it always produces the same ranked order, making tests straightforward.
- `PartnerRegistry` is the single place to add new partners or change affiliate configuration.
- `ClickTrackingService` uses a simple list today; swap it for a DB-backed adapter later without touching the API layer.
- VIN decoding and photo recognition are retained behind their existing service boundaries and are not required by the primary recommendation flow.
- Responses include `X-Request-Id` headers for request tracing.
