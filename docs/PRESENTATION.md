## ✨ Премиум-фичи

### 🎨 Carbon Design System
- **Тёмная тема** с углеродно-чёрным фоном и неоново-голубым акцентом `#00d4ff`
- **Glassmorphism** — эффекты стекла с `backdrop-filter: blur(20px)`
- **Анимированный фон** — силуэт автомобиля с glow-эффектом
- **Микровзаимодействия** — плавные появления сообщений, карточек, кнопок
- **Адаптивность** — идеально под Telegram и мобильные браузеры

### 🧠 AI-консультант (Чат-режим)
- **Пошаговый диалог** — 6 шагов: марка → модель → год → стиль вождения → сезон → бюджет
- **Распознавание текста** — понимает синонимы ("комфорт"/"комфортный"), частичные совпадения
- **Валидация** — дружелюбные подсказки при ошибках ввода
- **Typing indicator** — анимация "печатает..." для естественного общения

### 📝 Форма быстрого подбора
- **92 бренда** с моделями (Россия, Европа, Корея, Япония, США, Китай)
- **Умные селекты** — динамическая загрузка моделей при выборе марки
- **Radio-группы** — стиль вождения и сезон в премиум-дизайне
- **Валидация полей** — обязательные поля подсвечиваются

### 🎤 Голосовой ввод
- **SpeechRecognition API** — голосовой набор ответов
- **Wave-анимация** — визуальный индикатор прослушивания
- **Поддержка русского языка** — встроенное распознавание речи

### 📊 Результаты подбора
- **Совет AI** — экспертная рекомендация с анализом рынка
- **🔥 Народный выбор** — самая популярная модель с золотым бейджем
- **👑 Лучшая цена** — автоматический бейдж на дешёвом варианте
- **⭐ Рейтинг звёздами** — визуальная оценка товара
- **🛒 Кнопка "Купить"** — прямая ссылка на партнёра
- **📤 Поделиться** — Web Share API (Telegram, WhatsApp, соцсети)
- **Анимация загрузки** — кольцевой индикатор с прогресс-баром

### 🌍 Мультиязычность (8 языков)
- 🇷🇺 Русский · 🇬🇧 English · 🇰🇿 Қазақша · 🇺🇿 O'zbekcha
- 🇰🇬 Кыргызча · 🇹🇯 Тоҷикӣ · 🇦🇲 Հայերեն · 🇬🇪 ქართული
- **Автоопределение** — сохранение выбора в `localStorage`
- **Динамический перевод** — без перезагрузки страницы

### 🗂️ Навигатор по деталям
- **SVG-иконки** — премиум-векторная графика для каждой категории
- **Активный бейдж** — текущий раздел (шины, двигатель, подвеска и т.д.)
- **Coming Soon** — заглушки для будущих разделов
- **Горизонтальный скролл** — удобная навигация на мобильных

### 💻 Backend Architecture
- **Flask + REST API** — эндпоинты `/api/recommend_tires`, `/api/brands`, `/api/lang`
- **DeepSeek AI** — интеграция с LLM для генерации рекомендаций
- **Mock Partner API** — симуляция каталога товаров с ценами и рейтингами
- **Prometheus метрики** — мониторинг производительности
- **Structured logging** — структурированные логи через structlog
