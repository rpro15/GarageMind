# 🚗 GarageMind AI — Презентация проекта 2026

**Premium AI-консультант по подбору шин | Telegram Mini App + DeepSeek AI + RAG**

---

## 📋 О проекте

GarageMind AI — это интеллектуальная система подбора шин, которая сочетает:

| Технология | Применение |
|:-----------|:-----------|
| 🧠 **DeepSeek AI** | Генерация персонализированных рекомендаций |
| 📚 **RAG (ChromaDB)** | Семантический поиск по каталогу + отзывам |
| 💾 **Redis** | Молниеносное кэширование частых запросов |
| 📱 **Telegram Mini App** | Удобный интерфейс с голосовым вводом |
| 🌍 **8 языков** | Русский, English, Қазақша, O'zbekcha и др. |
| 🔍 **Парсинг форумов** | Сбор реальных отзывов с drive2.ru и 7+ площадок |

## 🆕 Ключевые обновления 2026 года

### 1. ⚡ Redis-кэширование
**Было:** Каждый запрос → DeepSeek API (3-5 сек, деньги за токены)  
**Стало:** Частые запросы → Redis (1-5 мс, бесплатно)
- Рекомендации: TTL 10 минут
- Бренды/модели: TTL 1 час
- Fallback-режим при недоступности Redis

### 2. 📚 RAG-система (Retrieval Augmented Generation)
- **ChromaDB** — векторное хранилище для семантического поиска
- **Эмбеддинги** через DeepSeek API (1024 мер)
- **Гибридный поиск** — векторное сходство + фильтр по метаданным
- **Knowledge Base** — JSON + SQLite для offline-данных

### 3. 🔍 Парсинг реальных отзывов
Сбор отзывов владельцев с 8 популярных площадок СНГ:

| Площадка | Тип | Статус |
|:---------|:---:|:------:|
| drive2.ru | Автопортал, бортовые журналы | ✅ |
| drom.ru | Раздел отзывов о шинах | ✅ |
| pnevo.ru | Шинный портал | ✅ |
| forum.toyota.ru | Toyota-клуб | ✅ |
| kia-forum.ru | Kia-клуб | ✅ |
| vwts.ru | Volkswagen-клуб | ✅ |
| skoda-forum.ru | Skoda-клуб | ✅ |
| hyundai-forum.com | Hyundai-клуб | ✅ |

### 4. 👤 Персонализация (User History)
- История запросов хранится в **Redis** (быстрый доступ) + **SQLite** (постоянно)
- AI помнит: марку, модель, стиль вождения, сезон, бюджет
- При повторном обращении не спрашивает одно и то же
- Учитывает предыдущие покупки (через партнёрские ссылки)

### 5. 📊 Сравнение товаров
- Эндпоинт: `POST /api/compare_tires`
- Выберите 2–4 шины → получите таблицу сравнения от AI
- Критерии: цена, износостойкость, шумность, сцепление, стиль вождения

### 6. 📱 PWA — установка на iPhone (без App Store)
**Проблема в РФ:** App Store не работает для российских пользователей.
**Решение:** Наше приложение — **Progressive Web App (PWA)**!

| Шаг | Действие на iPhone |
|:---:|:-------------------|
| 1️⃣ | Откройте `rpro.su` в **Safari** |
| 2️⃣ | Нажмите **«Поделиться»** (квадрат со стрелкой) |
| 3️⃣ | Выберите **«На экран «Домой»»** |
| 4️⃣ | Готово! 🎉 Иконка на рабочем столе |

**Что даёт PWA:**
- ✅ **Полноэкранный режим** — без адресной строки браузера
- ✅ **Офлайн-доступ** — Service Worker кэширует данные
- ✅ **Push-уведомления** — даже когда приложение закрыто
- ✅ **Не нужен App Store** — никаких санкций и блокировок
- ✅ **Единая иконка** для iPhone, Android, Telegram

### 8. ⚙️ Полная конфигурация через .env
Добавлены все параметры:
- `CACHE_TTL_*` — настройка времени жизни кэша
- `COLLECTOR_DAILY_LIMIT` — лимит сбора отзывов

## 🔌 API Endpoints (новые)

### POST /api/compare_tires — Сравнение товаров
```json
{
  "products": [
    {"id": "1", "name": "Michelin Pilot Sport 4", "price": 12400, "rating": 4.5},
    {"id": "2", "name": "Continental PremiumContact 6", "price": 10800, "rating": 4.3}
  ]
}
```
→ Возвращает таблицу сравнения + рекомендацию AI

### POST /api/user/history — История пользователя
```json
{
  "user_id": "tg_12345",
  "brand": "Toyota",
  "model": "Camry",
  "driving_style": "comfort",
  "season": "summer"
}
```
→ Сохраняет предпочтения, при следующем запросе AI учитывает их

## 🎯 Cтек технологий

| Компонент | Технология |
|:----------|:-----------|

| CI/CD | GitHub Actions |

## 🚀 Быстрый запуск

```bash
# Локально
git clone https://github.com/rpro15/GarageMind.git
cd GarageMind
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # отредактировать
python -m app.main

# Docker
docker compose up --build

# Заполнить БД начальными данными
docker compose exec api python -m app.services.database.migrations.seed_data

# Запустить сбор отзывов
docker compose exec api python -m app.services.sources.forum_scraper
```
