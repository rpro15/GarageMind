# 🔧 Отчёт об исправлениях GarageMind AI

## 📋 Найденные проблемы и что сделано

### 🚨 Критические (почему пропадал ввод)

| # | Проблема | Где | Исправление |
|---|----------|-----|-------------|
| 1 | `/api/chat` не работал → 404 | routes.py | Добавлен fallback на локальный парсинг (`handleLocalParse`) |
| 2 | `isProcessing` зависал в `true` | scripts.js | Добавлен `finally { enableInput() }` блок во все асинхронные функции |
| 3 | Нет таймаутов на fetch | scripts.js | Добавлен `AbortController` с таймаутом 30с для чата и 45с для рекомендаций |
| 4 | Поле ввода не блокировалось | scripts.js | Добавлено `chatInput.disabled = true` при отправке + `enableInput()` после |
| 5 | Нет fallback при 404 API | scripts.js | `handleLocalParse()` — локальный парсер русских названий |
| 6 | Голосовой ввод не отключался при ошибке | scripts.js | Добавлен `stopListening()` в `recognition.onerror` |

### 🐛 Средние

| # | Проблема | Исправление |
|---|----------|-------------|
| 7 | Кракозябры в ответах DeepSeek | Добавлена обработка ошибок + русские заглушки при отсутствии API-ключа |
| 8 | `addTyping()` без `removeTyping()` в catch | Все `removeTyping()` теперь гарантированно вызываются |
| 9 | Нет кнопки "Начать заново" | Добавлена `addResetButton()` + CSS, показывается после 4 сообщений |
| 10 | Двойные приветствия | Унифицирован `startChat()` — пробует AI, если нет → локальное приветствие |
| 11 | `resetChat()` вызывал несуществующую `askNextQuestion()` | Заменён на `startChat()` |
| 12 | Нет проверки на дубликаты вызовов | Добавлена проверка `isProcessing` в начале `sendRecommendation` |

### ⚡ Оптимизации
